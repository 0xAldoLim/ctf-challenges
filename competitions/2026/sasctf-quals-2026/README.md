# SAS CTF 2026 Quals

This entry catalogs 23 original challenge directories and 24 distinct tasks. The two Escape from Guba tasks share the original `game-guba` directory. All entries are provenance-only. Redistribution permission for the upstream challenge materials could not be verified.

The catalog uses the [upstream competition README](https://github.com/Team-Drovosec/sasctf-quals-2026/blob/4a4c403f80ee1772185a967aa6ad7226d6708968/README.md) at commit `4a4c403f80ee1772185a967aa6ad7226d6708968`. See the [competition site](https://ctf.thesascon.com) and [CTFtime event](https://ctftime.org/event/3109).
